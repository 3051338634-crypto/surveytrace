# 调研证据台 SurveyTrace

问卷 CSV 的本地质检、结论证据追溯与可撤销清洗影响对比工作台。应用在百度搭子 PC 端生成并迭代，当前版本 **v0.3.1**。

## 功能

- CSV 在浏览器本地解析；确认字段类型，逐行查看缺失、重复、非法数值与超范围提示。
- 默认保留全部记录，人工排除或恢复样本后，统计与报告同步重算并记录操作。
- 展开字段、分母、计算口径与原始行明细，核对每条结论。
- 在相同筛选条件下对比原始与当前样本的有效 N、均值、中位数和分类占比。
- 导出独立 HTML 报告、当前样本 CSV，并支持浏览器打印 PDF。

## 数据与能力说明

内置 120 行数据全部由程序合成，不是真实调研。当前摘要由本地规则生成，未接入外部大模型。应用没有将导入问卷上传到服务器或模型的接口；网站托管请求仅用于载入静态代码。没有经过实测的用户量、效率提升或商业效果声明。
